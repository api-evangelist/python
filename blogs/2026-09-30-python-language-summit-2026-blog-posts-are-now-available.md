On July 14th, 2026, 47 Python core developers and special guests sat down at the Python Language Summit , this year held in Kraków, Poland at EuroPython 2026, to discuss many topics about the future of the Python programming language, including free-threading, Rust, garbage collectors, type annotations, and namespacing. This marked the first time the Python Language Summit had been hosted in Europe in 15 years, when the event was held in Florence on June 19th, 2011 . Going forward, the Python Language Summit will alternate between PyCon US and EuroPython on a yearly basis.
